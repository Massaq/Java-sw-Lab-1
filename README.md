## Опис проєкту
Проєкт реалізує предметну модель системи сповіщень та сервіс їх обробки згідно з принципами **Data-Oriented Programming (DOP)** у Java 21:
- **Незмінні дані (Immutable Data):** Реалізовані за допомогою `record` (`TextMsg`, `ImageMsg`, `AudioMsg`) з валідацією в компактних конструкторах.
- **Закрита ієрархія типів (Sealed Types):** Інтерфейс `Notification` оголошено як `sealed interface`, що явно обмежує перелік допустимих реалізацій.
- **Відокремлення даних від бізнес-логіки:** Обробка сповіщень винесена в окремий клас `NotificationProcessor`.
- **Pattern Matching & Switch Expressions:** Метод `process(Notification)` використовує вичерпний `switch` з деконструкцією записів (Record Patterns) без гілки `default`.
- **Text Blocks:** Форматування результату виконується через багаторядкові текстові блоки (`"""`).

Усі класи розташовані в пакеті `ua.kpi.comsys.dop`.
